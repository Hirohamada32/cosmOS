## cosmOS: 
An educational operating system project built to explore operating-system design from the ground up.
Inherit the code base from "OS in 1000 lines", this project is aiming to explore general operating system designs like Linux and xv6 for educational purpose
<br>
cosmOS is based on the reference implementation from Operating System in 1,000 Lines by Seiya Nuta, licensed under the MIT License.
